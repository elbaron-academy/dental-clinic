# MVP Product Requirements

The MVP is a small dental clinic workflow covering:
- Clinic/doctor setup
- Phone + password authentication
- Doctor, Assistant, Receptionist roles
- Patient registration
- Appointments/check-in
- Active doctor visit
- Diagnosis/procedure/treatment/medication recording
- Visit history
- Follow-up visits
- Basic payment balance tracking
- Configurable payment methods via Django Admin

Full invoicing/accounting is outside the initial MVP.
