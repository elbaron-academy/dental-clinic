# Flutter Skill

## Responsibilities
- Read approved business logic, sprint tasks, and API contracts.
- Write Flutter/Dart code for approved tasks.
- Keep implementation aligned with the Web/PWA behavior and API contract.

## Explicit restriction
For the current MVP, DO NOT:
- run Flutter
- run an emulator/device
- execute Flutter tests
- claim runtime verification

The agent only writes and reviews code. Flutter execution/testing can be enabled by Team Leader in a future sprint.
